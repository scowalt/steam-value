These files preserve the disabled workflows from commit `4aba6c2a281432a434ab0e37c260a6b1645a4825`. They are documentation, outside `.github/workflows`, not active workflows or an alternate deployment controller. Use the [replacement Actions handoff](../github-actions.md). Existing hosted workflow states and past runs are not changed or deleted by archiving these source definitions.
