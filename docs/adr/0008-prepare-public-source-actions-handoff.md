# Make public GitHub the sole development and release platform

Status: accepted on 2026-11-01. The owner approved local implementation and the coordinated hosted cutover, scoped CI credential configuration, gated deployment and public visibility after final audits. Execution and acceptance evidence are tracked in [#42](https://github.com/scowalt/steam-value/issues/42).

Use the public `scowalt/steam-value` repository for all source, issues, PRs and development, and GitHub-hosted Actions for all CI/CD. This replaces ADR 0006's private Woodpecker provider choice upon the approved handoff, rather than establishing a permanent hybrid. Keep Steam Status, authenticated Steel, D1, Access, credentials and audit evidence private; they are runtime resources, not a second development home.

Separate credential-free PR verification from main-only artifact publication and production environments. Preserve private R2 exact-tested-artifact promotion, integrated policy gates, fresh current-main checks, serialization and narrow credentials. Actions artifacts bind provider, run, attempt and commit; no legacy artifact fallback or rebuild is allowed. An explicit repository activation variable keeps the prepared workflow verification-only until Woodpecker is drained and retired.

The patch archives active Woodpecker configurations/bootstrap and the legacy Actions controller outside executable workflow paths. The existing remote main remains the live controller until an approved delivery freezes promotions and disables this repository's Woodpecker entrypoints before merging. Do not restore a second controller to work around a failed handoff. See the [Actions runbook](../ci/github-actions.md) for delivery, environment restrictions, acceptance and rollback boundaries. ADRs 0004 and 0007 still govern native D1 and the retired Turso/export; no runtime behavior or data migration is part of this decision.
